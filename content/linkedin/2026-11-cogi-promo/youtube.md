## Title

Claude forgets. Cogi doesn't. A free memory for Claude Code #Shorts

## Description

Cogi keeps every message you and Claude exchange, word for word, in one folder on your own computer. No account, no API key, no AI calls to save a message. When something drops out of the conversation, Claude searches Cogi and gets your exact words back.

Install (needs Claude Code and uv):
claude plugin install cogito-mem --marketplace meridian21lab/cogito-mem

Try it: tell Claude "Let's call the staging server acorn", run /clear, then ask what you called it.
